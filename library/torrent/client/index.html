Как работает поиск пиров


Клиент может использовать несколько механизмов одновременно:




    

  • Trackers — сообщают клиенту адреса пиров конкретной раздачи.
    • 

  • DHT — распределённый поиск пиров без центрального трекера.
    • 

  • PeX — обмен адресами пиров между подключёнными участниками.
    • 



Состояние трекеров меняется со временем. В списках могут встречаться временно недоступные адреса.
