WINDOWS / DIAGNOSTICS

Диагностика Windows

Проверка системных файлов, хранилища компонентов, дисков, драйверов и журналов.

Проверка и исправление — разные действия

Сначала выполни диагностику и посмотри результат. Команды восстановления запускай отдельно, когда понятна причина.

Команды с меткой «Администратор» запускаются из Windows Terminal или CMD, открытых через «Запуск от имени администратора». Не закрывай окно до завершения проверки или восстановления.

Сведения и журналы

Эти команды в основном собирают информацию.

Подробности об ОС и ПКCMD

Сбор информации об установленной ОС, BIOS, памяти и конфигурации.

systeminfo
Без прав администратора
История стабильностиWin + R

Временная шкала сбоев приложений, ошибок и обновлений.

perfmon /rel
Без прав администратора
Системные журналыWin + R

Просмотр ошибок и предупреждений в журналах Windows.

eventvwr.msc
Без прав администратора
Состояние физических дисковPowerShell

Показывает сведения о дисках, которые предоставляет Windows.

Get-PhysicalDisk | Format-Table FriendlyName, HealthStatus, OperationalStatus
Без прав администратора
Устройства с ошибкамиPowerShell

Проверяет, есть ли устройства с ошибочным статусом.

Get-PnpDevice -Status ERROR
Без прав администратора

Проверка системных файлов и образа Windows

Запускай эти команды в терминале от имени администратора.

Только проверить системные файлыCMD · Admin

Проверяет целостность защищённых системных файлов без исправления.

sfc /verifyonly
Администратор
Быстрая проверка хранилища компонентовCMD · Admin

Проверяет, обнаружено ли ранее повреждение хранилища компонентов.

DISM /Online /Cleanup-Image /CheckHealth
Администратор
Полное сканирование хранилища компонентовCMD · Admin

Сканирует образ Windows на повреждения; не выполняет восстановление.

DISM /Online /Cleanup-Image /ScanHealth
Администратор
Проверить и восстановить системные файлыCMD · Admin

Проверяет защищённые системные файлы и пытается восстановить найденные повреждения.

sfc /scannow
Администратор
Восстановить хранилище компонентовCMD · Admin

Восстанавливает хранилище компонентов; может использовать Windows Update и интернет.

DISM /Online /Cleanup-Image /RestoreHealth
Администратор

Проверка дисков

Команды ниже не содержат параметров принудительного исправления.

Проверка файловой системыCMD

Показывает состояние файловой системы тома C: без параметра /f.

chkdsk C:
Без прав администратора
Онлайн-сканирование NTFSCMD · Admin

Выполняет онлайн-сканирование NTFS-тома; может сообщить о необходимости отдельного исправления.

chkdsk C: /scan
Администратор
Сведения о томахPowerShell

Показывает файловую систему, состояние и свободное место.

Get-Volume | Format-Table DriveLetter, FileSystem, HealthStatus, SizeRemaining, Size
Без прав администратора

Рекомендуемый порядок проверки

Когда Windows ведёт себя нестабильно.

  1. Открой «Монитор стабильности» через perfmon /rel и найди время сбоя.
  2. Проверь системный образ командами DISM /CheckHealth или /ScanHealth.
  3. Запусти sfc /scannow, чтобы проверить и восстановить защищённые системные файлы.
  4. Для диска сначала используй обычный chkdsk C: или онлайн-сканирование NTFS.

Параметры /r и /f запускают проверку с исправлением; обычная диагностика и восстановление — разные этапы.
