С чего начать

Три команды, которые помогают быстро понять состояние системы.

  • winver — версия и сборка Windows.
  • taskmgr — загрузка процессора, памяти, дисков и список процессов.
  • msinfo32 — подробные сведения об оборудовании и системе.

Как пользоваться командами

Короткая памятка перед запуском.

  • Win + R — запуск системных окон и оснасток.
  • CMD — классическая командная строка.
  • PowerShell — команды и объекты для подробной диагностики.
  • Метка «Администратор» означает, что терминал нужно открыть с повышенными правами.

Кнопка «Копировать» помещает команду в буфер обмена. Она сама ничего не запускает.
