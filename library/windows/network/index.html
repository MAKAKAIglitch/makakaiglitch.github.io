WINDOWS / NETWORK

Сеть и интернет

Команды для проверки IP, DNS, маршрутов, сетевого адаптера и доступности узлов.

Базовая диагностика — CMD

Команды можно выполнять в обычной командной строке.

IP-конфигурацияCMD

IP-адреса, шлюз, DHCP, DNS и MAC-адреса адаптеров.

ipconfig /all
Без прав администратора
Кэш DNSCMD

Показывает записи локального DNS-кэша.

ipconfig /displaydns
Без прав администратора
Проверка IP-доступностиCMD

Четыре ICMP-запроса к адресу Cloudflare; проверяет базовую связность.

ping -n 4 1.1.1.1
Без прав администратора
Проверка DNS и доступаCMD

Проверяет разрешение имени и ICMP-доступность узла.

ping -n 4 example.com
Без прав администратора
Маршрут до узлаCMD

Показывает промежуточные маршрутизаторы без DNS-имён.

tracert -d 1.1.1.1
Без прав администратора
DNS-запросCMD

Показывает, какой DNS-ответ получен для домена.

nslookup example.com
Без прав администратора
Таблица маршрутизацииCMD

Показывает IPv4/IPv6-маршруты и интерфейсы.

route print
Без прав администратора
Таблица ARPCMD

Показывает известные локальные соответствия IP и MAC.

arp -a
Без прав администратора
Сведения о Wi-FiCMD

SSID, тип радио, канал, скорость и состояние Wi-Fi.

netsh wlan show interfaces
Без прав администратора
Очистить локальный DNS-кэшCMD

Очищает кэш DNS на этом ПК; Windows заново запросит записи при необходимости.

ipconfig /flushdns
Без прав администратора

PowerShell — сеть

Команды показывают конфигурацию и проверяют TCP-подключение.

IP и шлюз интерфейсовPowerShell

Получает IP-конфигурацию, адреса и DNS-серверы интерфейсов.

Get-NetIPConfiguration
Без прав администратора
DNS-серверы интерфейсовPowerShell

Показывает DNS-серверы для сетевых интерфейсов.

Get-DnsClientServerAddress
Без прав администратора
Разрешение DNS-имениPowerShell

Показывает DNS-ответ без использования ping.

Resolve-DnsName example.com
Без прав администратора
Проверка TCP-портаPowerShell

Проверяет TCP-подключение к порту 443 и выводит диагностику.

Test-NetConnection example.com -Port 443
Без прав администратора

Как читать результаты

Подсказки по частым полям.

  • Default Gateway — адрес шлюза, через который ПК выходит в другие сети.
  • DNS Servers — резолверы для поиска IP-адресов по именам.
  • Destination host unreachable — узел или маршрут недоступен; причина может быть на ПК, роутере или дальше по пути.
  • Request timed out — ответ не получен вовремя; некоторые узлы фильтруют ICMP, поэтому один ping не доказывает отсутствие доступа к сервису.

Команда ipconfig /flushdns меняет только локальный DNS-кэш. Остальные команды предназначены для просмотра или проверки соединения.
