Методика измерений

Что именно проверяется и как читать результаты

HTTP

Доступность

GitHub Actions runner выполняет HTTPS-запрос к проверочному адресу сервиса. Сохраняются HTTP-код, результат запроса и время получения заголовков ответа.

ms

Задержка

HTTP latency включает сетевой путь, установление соединения при необходимости и ожидание ответа сервера. Это не чистый ICMP RTT и не измерение из твоего домашнего роутера.

API

Официальные статусы

Для GitHub, Cloudflare, Discord и OpenAI дополнительно опрашиваются официальные Status API. Они показываются отдельно от сетевого ответа.

365d

История и uptime

За 24 часа сохраняются 5-минутные измерения, за 7 дней — 15-минутные агрегаты, за 30 дней — часовые, за 365 дней — дневные. Пропуски расписания снижают покрытие и не считаются успешными проверками.

Проверки без API

Для OpenStreetMap, BeaconDB, Wildberries, Ozon и Rockstar монитор делает обычный HTTPS GET к публичной странице. Отдельный API сервиса не требуется: фиксируются HTTP-ответ, код и время отклика. Для Roblox такая проверка тоже основная, а официальный Status API добавлен лишь как дополнительный источник. Это показывает доступность сайта/endpoint, но не гарантирует работу входа, платежей, матчмейкинга, геопоиска или других внутренних функций.

Откуда выполняются проверки

Плановые запросы выполняются GitHub Actions на стандартном облачном runner. Это одна точка наблюдения, а не глобальная сеть зондов и не проверка из сети каждого пользователя. Региональная блокировка, проблемы отдельного провайдера или DNS могут отличаться от результата проверки.

Как определяется инцидент

Одиночный неудачный запрос записывается как неуспешная точка. Инцидент открывается после двух последовательных проблемных проверок и закрывается после двух последовательных нормальных проверок. Поэтому краткие сетевые всплески не превращаются в длинные инциденты.

Что означает HTTP-код

Ответы 2xx и 3xx считаются доступными. Ответы 4xx означают, что узел ответил, но запрос ограничен или отклонён; они отмечаются как деградация. Ошибки сети, тайм-ауты и ответы 5xx считаются недоступностью проверочного endpoint.

Как работает мониторинг

GitHub Actions выполняет HTTPS-проверки 111 сервисов, измеряет время ответа, получает дополнительные официальные статусы там, где есть публичный Status API, обновляет историю и публикует JSON на GitHub Pages.

Стандартные GitHub-hosted runners в публичных репозиториях бесплатны. Расписание GitHub Actions может иногда задерживаться из-за нагрузки платформы.
