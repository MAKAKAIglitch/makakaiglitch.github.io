Внешняя DNS-проверка

Открой независимый DNS leak test, если браузер или сеть блокируют запросы к сервису проверки.

Открыть bash.ws ↗

Для проверки внешнего IP используются ipify; WebRTC создаёт STUN-запросы к Google и Cloudflare; DNS-пробы отправляются к bash.ws. Эти внешние сервисы получают технические данные, необходимые для своих проверок.

Сравнение работает только после сохранения исходного результата. Без него адреса показываются как наблюдения, а не как вердикт об утечке. Результат относится только к этому браузеру и текущей сети.

Что именно проверяется

Проверки разделены, потому что IP, WebRTC и DNS используют разные сетевые пути.

IPv4 / IPv6
Адреса, которые видят внешние сервисы.
WebRTC
IP-кандидаты, которые браузер может раскрыть через STUN.
DNS
Рекурсивные DNS-серверы, пришедшие к тестовой авторитетной зоне.

DNS-тест использует bash.ws: сервис получает уникальный идентификатор теста и видит IP DNS-резолверов, которые запрашивают уникальные имена. Эти данные передаются стороннему сервису.
