Как это работает. GitHub Pages запускает интерфейс и сборку файла в браузере. Для регистрации нового WARP-устройства используется публичный API-сервис, как и в warp-generation.github.io. API создаёт профиль и возвращает ключи; сайт собирает .conf и не сохраняет его на сервере. Важно: приватный ключ создаётся сторонним API, поэтому оператор этого API потенциально может его видеть. Если такой уровень доверия не подходит, используй ручной режим с уже имеющимся конфигом.

AmneziaWG 2.0 — шумовые пакетыADVANCED

S1–S4 и H1–H4 фиксируются в WARP-совместимых значениях: S = 0, H = 1 / 2 / 3 / 4.

Данные остаются в этой вкладке браузера.

Приватность: локальный редактор не отправляет введённые ключи на сервер и не сохраняет их в localStorage. Не публикуй готовый .conf: внутри приватный ключ.

02 / Результат

Проверь настройки и скачай файл для импорта в AmneziaWG или WireGuard.

Локальная сборка не регистрирует новое устройство и не проверяет доступность endpoint.
