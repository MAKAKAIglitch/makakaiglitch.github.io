i

Как работает генерация. GitHub Pages — статический хостинг: он не может самостоятельно регистрировать WARP-устройство и выдавать новые ключи. Поэтому кнопка открывает awgconfig.com — открытый генератор, который регистрирует устройство через API Cloudflare, применяет выбранные параметры и позволяет скачать готовый .conf. После открытия останется нажать Generate на странице генератора. Исходный код ↗

01 / Исходные данные

Вставь существующий WireGuard-конфиг — поля заполнятся автоматически. Либо введи значения вручную.

AmneziaWG 2.0 — шумовые пакетыADVANCED

S1–S4 и H1–H4 фиксируются в WARP-совместимых значениях: S = 0, H = 1 / 2 / 3 / 4.

Данные остаются в этой вкладке браузера.

Приватность: локальный редактор не отправляет введённые ключи на сервер и не сохраняет их в localStorage. Не публикуй готовый .conf: внутри приватный ключ.

02 / Результат

Проверь настройки и скачай файл для импорта в AmneziaWG или WireGuard.

Локальная сборка не регистрирует новое устройство и не проверяет доступность endpoint.
