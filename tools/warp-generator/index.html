WARP Generator

Собери конфигурацию WireGuard или AmneziaWG 2.0 на основе параметров своего Cloudflare WARP-аккаунта.

Важно: этот инструмент собирает файл из уже существующих ключей и параметров WARP. Он работает локально и не регистрирует новое устройство в Cloudflare. Для регистрации нового WARP-аккаунта есть отдельный внешний сервис.

Новый WARP-аккаунт ↗

01 / Исходные данные

Вставь существующий WireGuard-конфиг — поля заполнятся автоматически. Либо введи значения вручную.

AmneziaWG 2.0 — шумовые пакетыADVANCED

S1–S4 и H1–H4 зафиксированы в WARP-совместимых значениях: S = 0, H = 1 / 2 / 3 / 4. Эти поля не рандомизируются, чтобы не нарушить совместимость со стандартным WireGuard peer Cloudflare.

Данные остаются в этой вкладке браузера.

Приватность: страница не отправляет введённые ключи на сервер и не сохраняет их в localStorage. Не публикуй готовый .conf: внутри приватный ключ.

02 / Результат

Проверь настройки и скачай файл для импорта в AmneziaWG или WireGuard.

Генерация файла не проверяет доступность endpoint из твоей сети и не гарантирует соединение.
