Magnet → Torrent

Получение метаданных из magnet-ссылки и сохранение их в обычный .torrent-файл.

Тестовый режим Браузерный WebTorrent подключается только к WebRTC-совместимым пирам. Обычные TCP/UDP-пиры qBittorrent этот браузерный клиент напрямую не видит. Поэтому часть magnet-ссылок не сможет получить метаданные — это ограничение браузерного P2P, а не ошибка ссылки.

Метаданные получены Metadata ready

Для получения .torrent нужны метаданные info dictionary. Один infohash и имя из magnet-ссылки не содержат списка файлов, размеров и piece hashes — собрать полноценный торрент только из этих строк нельзя.

Ссылка и infohash используются браузером для подключения к WebRTC-пирам и трекерам. Сам файл и введённые данные на сервер сайта не отправляются.
