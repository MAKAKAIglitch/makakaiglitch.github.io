Маркер — приблизительная оценка. Круг появляется только если источник вернул числовой радиус ошибки.Сообщить об ошибке карты ↗

Источники: IPWHOIS (ipwho.is) для ISP и геоданных, RIPEstat RIS для BGP, IANA RDAP bootstrap для RIR и RDAP, Google Public DNS для PTR. Внешние сервисы получают проверяемый IP-адрес. У бесплатного IPWHOIS лимит 1 000 запросов в сутки на домен; данные о VPN/Tor в бесплатный ответ не входят. Числовой радиус геолокации показывается только если он пришёл от источника.
