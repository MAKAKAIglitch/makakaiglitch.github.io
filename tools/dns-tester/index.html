Готово к проверке DoH-серверов

Где поддерживается HTTPS / DoH

Firefox поддерживает встроенный и пользовательский URL DNS-over-HTTPS. Windows 11 позволяет задать шаблон DoH для совместимых DNS-серверов. На Android системная настройка «Частный DNS» использует DoT, поэтому для DoH нужно отдельное совместимое приложение или браузер.

Firefox DoH ↗Windows 11 DoH ↗

Где поддерживается TLS / DoT

Android 9 и новее: Настройки → Сеть и интернет → Частный DNS → имя хоста провайдера. Вводи имя без префикса tls://. На Linux и роутерах DoT доступен через совместимые резолверы и DNS-прокси, например systemd-resolved, Stubby или AdGuard dnsproxy.

Для tls://1.1.1.1 проверка сертификата по IP может не пройти. Для Cloudflare DoT обычно используют имя one.one.one.one с адресом 1.1.1.1.

Android Private DNS ↗AdGuard dnsproxy ↗

Где поддерживается QUIC / DoQ

DoQ требует отдельного DNS-клиента с поддержкой DNS-over-QUIC. Протокол поддерживают приложения AdGuard для Android и iOS, AdGuard Home и AdGuard dnsproxy. Обычный браузер и стандартное поле Android Private DNS не подключаются к произвольным DoQ-серверам.

Инструкция AdGuard DoQ ↗AdGuard dnsproxy ↗

В браузере измеряется время настоящего DNS-запроса через DoH, а не ICMP ping. DoT и DoQ показаны как конфигурации: JavaScript страницы не может напрямую открывать произвольные TCP/TLS и QUIC-соединения. Для них страница не показывает выдуманные значения задержки.
